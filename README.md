# MdjeBot

[![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python&logoColor=white)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-AGPL--3.0%20%2B%20Commons%20Clause-orange)](LICENSE)
[![Telethon](https://img.shields.io/badge/Telethon-1.44+-0088cc?logo=telegram)](https://github.com/LonamiWebs/Telethon)
[![Docs](https://img.shields.io/badge/Docs-GitHub%20Pages-blue?logo=github)](https://mdjes.github.io/mdjeBot/)

**ربات‌ساز** تلگرام برای ساخت ربات فروش وی‌پی‌ان روی پنل [پاسارگارد](https://github.com/PasarGuard/panel)، توسعه و نگهداری توسط **Mdje**.

شما تعرفهٔ ماهانه را تعیین می‌کنید؛ مشتری تعرفه را می‌خرد، در @BotFather یک ربات می‌سازد و **توکنش** را برای ربات‌ساز می‌فرستد؛ ربات‌ساز همین سورس را با آن توکن به یک **ربات فروش مستقل** برای او تبدیل و اجرا می‌کند (کانتینر، دیتابیس و Redis جدا).

**[مستندات کامل (فارسی)](https://mdjes.github.io/mdjeBot/)**

## نصب سریع (لینوکس)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mdjes/MdjeBot/main/scripts/mdjebot.sh)
```

اسکریپت فقط **توکن ربات‌ساز** (یک ربات جدید از @BotFather) و **آیدی عددی ادمین** را می‌پرسد و بقیه را خودکار انجام می‌دهد. بعد از نصب: `mdjebot`

### 🏭 ربات‌ساز (Builder)

| بخش | امکانات |
|------|---------|
| کاربر | انتخاب تعرفه ← پرداخت (کیف پول / کارت‌به‌کارت) ← ارسال توکن ← ساخت خودکار ربات؛ تست رایگان، تمدید، تغییر ادمین |
| **🧩 فروش پنل** | اتصال به پنل پاسارگارد شما؛ مشتری پنل (ادمین با حجم و مدت مشخص) می‌خرد، ادمین **خودکار** روی پنل ساخته و ربات او به آن **وصل می‌شود**؛ تمدید، حجم اضافه، هشدار مصرف و قطع خودکار با اتمام حجم |
| ادمین (داخل تلگرام) | تعرفه‌ها، پرداخت‌ها و رسیدها، ربات‌ها، پنل‌ها، کاربران، کارت‌ها، کد تخفیف، تنظیمات، ارسال همگانی، به‌روزرسانی همهٔ ربات‌ها |
| اشتراک | ماهانه؛ یادآوری تمدید، توقف خودکار در پایان و حذف پس از مهلت |
| امنیت | توکن‌ها و رمزها رمزنگاری‌شده، پیام حاوی توکن پاک می‌شود، هر ربات کانتینر و دیتابیس جدا دارد |

راهنما: [ربات‌ساز](https://mdjes.github.io/mdjeBot/docs/builder) و [فروش پنل](https://mdjes.github.io/mdjeBot/docs/builder/panels).

### 🤖 ربات (Bot)

ربات فروش وی‌پی‌ان روی پنل پاسارگارد: خرید و تحویل آنی، تمدید، کیف پول، پرداخت (کارت‌به‌کارت، ارز دیجیتال، استارز، درگاه)، تست، نمایندگی، کد تخفیف، وب‌اپ و پنل تحت وب.

- **طراحی تازه:** پیام‌ها و منوها با یک طراحی یکدست (عنوان، جداکننده، یک ایموجی برای هر فیلد، راهنمای 💡) بازنویسی شده‌اند.
- **منوی ادمین شیشه‌ای:** دکمه‌های پنل مدیریت و دکمه‌های داخل پیام‌های آن زیر پیام نمایش داده می‌شوند؛ نام، رنگ و **ایموجی متحرک** هر دکمهٔ منو از «⌨️ مدیریت دکمه‌های کیبورد» قابل تغییر است. قاب «「 」» همهٔ دکمه‌های ادمین از صفحهٔ ۶ همین بخش روشن و خاموش می‌شود.
- **منوی کاربران قابل تنظیم است:** در ربات‌های جدید منوی اصلی کاربران به‌صورت پیش‌فرض کیبورد پایین است. با روشن کردن تنظیم «دکمه‌های شیشه‌ای صفحه اصلی» می‌توانید آن را هم به دکمه‌های زیر پیام تبدیل کنید.
- **🎁 کدهای هدیه:** ادمین کد با مبلغ، تعداد استفاده و انقضا می‌سازد؛ هر کاربر هر کد را یک‌بار از «افزایش موجودی» یا `/gift` ثبت می‌کند و مبلغ به کیف پولش اضافه می‌شود.

## وب‌اپ (Telegram Mini App)

کنار ربات تلگرام، MdjeBot یک **وب‌اپ** کامل هم دارد: مشتری‌ها سرویس‌هایشان را می‌بینند و تمدید می‌کنند، کیف پول را شارژ می‌کنند و سرویس می‌خرند؛ شما هم کل فروشگاه را از یک **پنل مدیریت تحت وب** اداره می‌کنید. وب‌اپ روی همان وب‌سرور ربات اجرا می‌شود و چیز جدایی برای نصب ندارد.

### یک اپ، سه شکل

| | |
|---|---|
| 📲 **داخل تلگرام** | با یک دکمه در ربات (Mini App) باز می‌شود و کاربر **بدون ورود دستی** وارد حسابش می‌شود. |
| 🌐 **در مرورگر** | هر مرورگری؛ ورود با شمارهٔ تلفن (کد از ربات) یا **کلید API** شخصی. |
| 🏠 **نصب روی گوشی (PWA)** | با «نصب اپ روی صفحه اصلی» مثل یک اپ مستقل باز می‌شود؛ نام و آیکن اپ را ادمین تغییر می‌دهد. |

### 👤 اپ کاربر

| بخش | امکانات |
|------|---------|
| **خانه** | موجودی کیف پول، دسترسی سریع به سرویس‌ها، خرید و شارژ، و فعالیت اخیر |
| **سرویس‌ها** | جستجو، وضعیت هر سرویس، حجم و زمان باقی‌مانده، صفحه‌بندی |
| **مدیریت سرویس** | نمودار مصرف، لینک اشتراک و QR، لینک‌های دیگر، تمدید، افزایش زمان و حجم |
| **خرید** | ویزارد چندمرحله‌ای: پنل ← زمان ← پلن ← نام ← تأیید ← تحویل آنی |
| **کیف پول** | شارژ با کارت‌به‌کارت، ارز دیجیتال، استارز و TonPays (با نمایش بونوس هر روش)؛ تاریخچهٔ تراکنش‌ها |
| **نمایندگی و پروفایل** | خرید و مدیریت پنل نمایندگی، کلید API، راهنما و دانلود برنامه‌ها |

### 🛠 پنل مدیریت تحت وب

| بخش | امکانات |
|------|---------|
| **داشبورد و گزارش** | درآمد امروز و ۳۰ روز، رسیدهای در انتظار، نمودار درآمد و ثبت‌نام ۱۴ روز اخیر؛ گزارش‌ها و **گزارش فعالیت** ادمین‌ها |
| **فروش** | کاربران، سرویس‌ها، تراکنش‌ها، پلن‌های فروش و کد تخفیف |
| **زیرساخت** | پنل‌های پاسارگارد، نمایندگی‌ها و پلن‌های نمایندگی، درگاه‌های پرداخت |
| **ارتباط با کاربر** | پیام همگانی، کانال‌ها، متن‌های ربات و سیستم دعوت |
| **ظاهر ربات** | ویرایش متن‌ها، متن و رنگ و آیکن دکمه‌ها و **چیدمان منوی اصلی با کشیدن و رها کردن** |
| **تنظیمات و ابزارها** | همهٔ تنظیمات ربات، وضعیت سیستم، بکاپ دیتابیس و افزایش گروهی حجم و زمان |

### ✨ جزئیات

- **فارسی و English** با جهت راست‌به‌چپ کامل؛ تم **روشن، تیره یا خودکار** (هماهنگ با گوشی یا تلگرام).
- طراحی ریسپانسیو برای موبایل و دسکتاپ.
- وقتی وب‌اپ از دکمهٔ داخل ربات باز شود، تلگرام اطلاعات امضاشدهٔ کاربر را می‌دهد و **ورود خودکار** انجام می‌شود؛ هیچ فرمی پر نمی‌شود.

### 🚀 راه‌اندازی

دو چیز لازم است: وب‌سرور ربات روشن باشد (`FASTAPI_PORT`، پیش‌فرض `6160`) و `WEBAPP_URL` با **`https://`** و دامنهٔ معتبر تنظیم شود (تلگرام آدرس غیر HTTPS را قبول نمی‌کند). بعد با دستور `/webapp` (حساب ادمین) تست کنید.

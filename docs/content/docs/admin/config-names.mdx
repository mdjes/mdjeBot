اسمی که دکمهٔ **🎲 اسم پیشفرض** برای مشتری (هنگام خرید) و برای شما (ساخت کانفیگ برای کاربر) و در مینی‌اپ می‌سازد از **پنل مدیریت ← 🛍 فروش و محصولات ← 🏷 اسم پیشفرض کانفیگ** تنظیم می‌شود. پیش‌فرض همان ۹ حرف و عدد تصادفی است.

## الگوها

با یک دکمه یکی از الگوهای آماده را بگذارید یا با **✏️ الگوی دلخواه** خودتان بنویسید. بالای صفحه همیشه چند **نمونه** از اسمی که الگو می‌سازد دیده می‌شود.

| الگو | نمونه |
|------|-------|
| 🤖 اسم ربات + عدد `{bot}_{n5}` | `MdjeBot_48213` |
| 🆔 اسم ربات + آیدی + عدد ۵ رقمی `{bot}_{id}_{n5}` | `MdjeBot_989932570_48213` |
| 👤 یوزرنیم تلگرام + عدد `{user}_{n4}` | `Ferii550_4821` |
| 🔢 اسم ربات + آیدی + شمارهٔ خرید `{bot}_{id}_{seq}` | `MdjeBot_989932570_3` |
| 🎲 تصادفی (قدیمی) | `K7Q2M9XPA` |

بخش‌هایی که در الگوی دلخواه می‌توانید بگذارید:

| بخش | معنی |
|------|------|
| `{bot}` | اسم ربات؛ از دکمهٔ **🤖 اسم ربات** تنظیم می‌شود (اگر خالی باشد، تگ خود ربات) |
| `{id}` | آیدی عددی مشتری |
| `{user}` | یوزرنیم تلگرام مشتری (اگر نداشته باشد، اسم ربات) |
| `{seq}` | این چندمین خرید او است |
| `{n5}` | ۵ رقم تصادفی؛ عدد بین ۱ تا ۱۲ |
| `{r4}` | ۴ حرف بزرگ یا عدد تصادفی؛ عدد بین ۱ تا ۱۲ |

<Callout type="info" title="خط تیره و محدودیت پنل">
نام کانفیگ در پنل فقط **حروف انگلیسی، عدد و `_`** می‌پذیرد و ۳ تا ۳۲ کاراکتر است؛ پس خط تیره یا فاصله‌ای که در الگو بنویسید خودکار به `_` تبدیل می‌شود. اگر اسم از ۳۲ کاراکتر بیشتر شود، اول اسم ربات و یوزرنیم کوتاه می‌شوند و آیدی و عدد تصادفی می‌مانند. اگر اسم ساخته‌شده قبلاً در پنل بوده، چند رقم تصادفی به آخرش اضافه می‌شود تا یکتا باشد.
</Callout>

## گزینه‌های دیگر

| گزینه | کار |
|--------|-----|
| 🔠 **حروف** | همان‌طور که هست / همه کوچک / همه بزرگ؛ برای اسم ساخته‌شده و نام تایپی هر دو. حروف کوچک جلوی تکراری شدن `Neda` و `neda` را می‌گیرد. |
| 🏷 **پیشوند نام تایپی** | وقتی روشن باشد، اسمی که خود مشتری می‌نویسد (مثلاً `Neda`) با اسم ربات شروع می‌شود (`MdjeBot_Neda`). این‌طور کانفیگ‌هایی که از ربات ساخته شده‌اند در پنل از بقیه جدا هستند. پیشوند تکراری اضافه نمی‌شود و اگر اسم با پیشوند از ۳۲ کاراکتر بگذرد، ربات می‌گوید حداکثر چند کاراکتر مجاز است. |
| ⛔️ **کلمات ممنوعه** | کلماتی مثل `admin, root, support, test` که نباید داخل نام تایپی مشتری باشند؛ اگر باشد ربات اسم دیگری می‌خواهد. با ویرگول یا فاصله جدا کنید و برای پاک کردن `-` بفرستید. |
| ⚡️ **نام‌گذاری خودکار** | وقتی روشن باشد ربات از مشتری اسم نمی‌پرسد و بعد از انتخاب پلن (یا حجم و مدت در خرید دلخواه) مستقیم صفحهٔ تأیید خرید را با اسم پیشفرض نشان می‌دهد. اگر پنل در دسترس نباشد، مثل قبل از مشتری اسم می‌پرسد. |

کلمات ممنوعه و پیشوند فقط برای نامی است که **مشتری** تایپ می‌کند؛ اسمی که شما خودتان برای کاربر می‌نویسید دست نمی‌خورد.

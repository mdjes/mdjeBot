همهٔ تنظیمات تست رایگان در یک صفحه است: **پنل مدیریت ← 🎁 تست رایگان**.

| بخش | کار |
|------|-----|
| 🟢 / 🔴 روشن یا خاموش | با روشن شدن، دکمهٔ **🎁 دریافت تست** در **منوی اصلی** ربات (همان لحظه که کاربر `/start` می‌زند) دیده می‌شود، نه در بخش خرید. اگر هیچ پنلی تست ندهد، ربات خودش اولین پنل فعال را انتخاب می‌کند. |
| 📥 حجم | عدد به گیگابایت: `2` یعنی ۲ گیگ، `0.5` یعنی **۵۰۰ مگ**؛ `500mb` هم قبول است. |
| ⏰ مدت | تعداد روز (۱ تا ۳۶۵). |
| 📱 تأیید شماره | کاربر قبل از تست شمارهٔ خودش را تأیید می‌کند. |
| 🧩 انتخاب پنل‌ها | (وقتی بیش از یک پنل دارید) هر پنل جدا تست بدهد یا ندهد. |

حجم و مدت برای همهٔ پنل‌هایی که تست می‌دهند اعمال می‌شود. اگر برای یک پنل مقدار جدا می‌خواهید، از **منوی پنل‌ها ← پنل ← تنظیمات تست** همان پنل را تغییر دهید.

<Callout type="info" title="دکمه دیده نمی‌شود؟">
دکمه وقتی نمایش داده می‌شود که تست **روشن** باشد، **حداقل یک پنل فعال** تست بدهد و کاربر قبلاً تست نگرفته باشد. صفحهٔ بالا همین را می‌گوید: اگر روشن است ولی دکمه نیست، 🟡 و دلیلش را نشان می‌دهد.
</Callout>

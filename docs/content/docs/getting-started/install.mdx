این صفحه نصب **ربات‌ساز** را از صفر تا اولین `/start` توضیح می‌دهد. نصب کامل حدود ۵ تا ۱۰ دقیقه طول می‌کشد.

ربات‌ساز یک ربات تلگرامی است که شما مدیریتش می‌کنید: تعرفهٔ ماهانه تعیین می‌کنید، کاربر تعرفه را می‌خرد، در @BotFather یک ربات می‌سازد و توکنش را برای ربات‌ساز می‌فرستد؛ ربات‌ساز همین سورس را به یک ربات فروش اختصاصی برای او تبدیل می‌کند. توضیح کامل: [ربات‌ساز](/docs/builder).

## پیش‌نیازها

| مورد | توضیح |
|------|--------|
| سرور لینوکس | Ubuntu / Debian پیشنهادی است. اسکریپت روی Fedora، CentOS/RHEL، Arch، openSUSE و Alpine هم کار می‌کند (روی سیستم‌های تست‌نشده هشدار می‌دهد) |
| معماری | `amd64` یا `arm64` (ایمیج‌ها فقط برای این دو ساخته می‌شوند) |
| دسترسی | `root` یا کاربری با `sudo` (اسکریپت خودش با sudo دوباره اجرا می‌شود) |
| منابع | هر ربات مشتری حدود ۳۸۴ مگابایت رم می‌گیرد؛ دیسک خالی حداقل **۲ گیگابایت** |
| پورت‌های آزاد | `6161` تا `6163` برای سرویس‌ها و بازهٔ `7000`–`7999` برای ربات‌های مشتری — جزئیات در [پورت‌ها](/docs/getting-started/ports) |
| توکن ربات‌ساز | یک ربات **جدید** از [@BotFather](https://t.me/BotFather) برای خود ربات‌ساز |
| آیدی عددی ادمین | آیدی عددی اکانت تلگرام خودتان (مثلاً از @userinfobot) |

<Callout type="info" title="Docker لازم نیست از قبل نصب باشد">
اگر Docker روی سرور نباشد، اسکریپت خودش آن را نصب می‌کند (از `get.docker.com` یا پکیج‌منیجر سیستم).
</Callout>

---

## اجرای اسکریپت

روی سرور اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mdjes/MdjeBot/main/scripts/mdjebot.sh)
```

اسکریپت این کارها را خودکار انجام می‌دهد:

- اگر root نباشید، خودش با `sudo` دوباره اجرا می‌شود
- سیستم‌عامل و پکیج‌منیجر را تشخیص می‌دهد (`apt-get`، `dnf`، `yum`، `pacman`، `zypper`، `apk`)
- ابزارهای پایه (`curl`، `openssl`، `nano`، …) را نصب می‌کند
- دستور **`mdjebot`** را ثبت می‌کند تا بعداً فقط با همین یک کلمه منو را باز کنید

دفعات بعد کافی است بزنید:

```bash
mdjebot
```

منوی مدیریت باز می‌شود:

## مراحل نصب

<Steps>
<Step>

### انتخاب حالت نصب و برنچ

حالت **Docker** (گزینهٔ `1`) را انتخاب کنید؛ نصب Native برای ربات‌ساز پشتیبانی نمی‌شود. بعد برنچ **`main`** (پایدار) را بزنید (`dev` فقط برای تست است).

</Step>
<Step>

### بررسی‌های خودکار

اسکریپت قبل از هر کاری این موارد را چک می‌کند:

- **نصب قبلی:** اگر قبلاً نصب شده باشد می‌پرسد `Continue (will keep existing .env and data)? (y/N):` — با `y` ادامه می‌دهد و `.env` و دیتای قبلی دست نمی‌خورد.
- **فضای دیسک:** حداقل ۲۰۴۸ مگابایت.
- **Docker:** اگر نصب نباشد نصبش می‌کند.
- **پورت‌ها:** `6161`، `6162`، `6163`. اگر یکی توسط برنامهٔ دیگری اشغال باشد می‌پرسد `Continue anyway? (y/N):`.

</Step>
<Step>

### وارد کردن اطلاعات

<CliPanel title="Credentials">
{`[*] Bot Builder — the bot your customers use to create their own bots.
  Builder BOT_TOKEN:
  Your numeric Telegram ID(s), comma separated (see @userinfobot):`}
</CliPanel>

فقط همین دو مورد پرسیده می‌شود.

<Callout type="info" title="API_ID و API_HASH پرسیده نمی‌شود">
نصب با مقادیر عمومی تلگرام کار می‌کند. اگر خواستید اپ شخصی خودتان را از [my.telegram.org/apps](https://my.telegram.org/apps) بسازید و جایگزین کنید (پیشنهاد می‌شود وقتی تعداد ربات‌ها زیاد شد، چون همهٔ ربات‌های مشتری از همین دو مقدار استفاده می‌کنند)، از منو بزنید: `mdjebot` ← `12` ← `5) Change API_ID / API_HASH`.
</Callout>

<CliPrompt
  label="Builder BOT_TOKEN:"
  required
  hint="توکن یک ربات جدید از @BotFather؛ این رباتی است که مشتری‌ها با آن صحبت می‌کنند."
/>

<CliPrompt
  label="Your numeric Telegram ID(s):"
  required
  hint="آیدی عددی ادمین(های) ربات‌ساز؛ چند آیدی را با کاما جدا کنید، مثل 111111111,222222222"
/>

اگر فایل `.env` از قبل وجود داشته باشد، این مرحله رد می‌شود.

</Step>
<Step>

### ساخت خودکار بقیهٔ تنظیمات

این موارد **پرسیده نمی‌شوند** و خودکار ساخته می‌شوند: رمز root دیتابیس (تصادفی ۳۲ کاراکتری)، کلید رمزنگاری توکن‌ها (`BUILDER_SECRET_KEY`)، و تگ ایمیج.

<Callout type="warn" title="از .env بکاپ بگیرید">
`BUILDER_SECRET_KEY` توکن ربات مشتری‌ها را در دیتابیس رمزنگاری می‌کند. بدون آن، توکن‌های ذخیره‌شده خوانا نیستند. فایل `/opt/mdjebot/.env` را جای امن نگه دارید.
</Callout>

</Step>
<Step>

### بالا آمدن سرویس‌ها

اسکریپت `docker-compose.yml` را دانلود و اعتبارسنجی می‌کند، ایمیج را از `ghcr.io/mdjes/mdjebot` می‌کشد و کانتینرها را بالا می‌آورد: `mdjebot-builder` (ربات‌ساز)، `mdjebot-mariadb`، `mdjebot-redis` و `mdjebot-phpmyadmin`. اگر ربات‌ساز چند ثانیه بعد از شروع بایستد (مثلاً توکن اشتباه است)، آخرین خطوط لاگ را نشان می‌دهد.

<Callout type="info">
اولین بالا آمدن MariaDB ممکن است چند دقیقه طول بکشد.
</Callout>

</Step>
<Step>

### خلاصهٔ نصب و لاگ زنده

در پایان مسیرها، ایمیج، پورت‌ها و مراحل بعدی چاپ می‌شود و بعد **لاگ زندهٔ ربات‌ساز** نمایش داده می‌شود. وقتی دیدید `Builder bot connected as @...`، `Ctrl+C` بزنید و بعد Enter تا به منو برگردید.

</Step>
</Steps>

## اولین ورود

1. در تلگرام ربات‌سازتان را باز کنید و `/start` بزنید؛ با `/admin` یا دکمهٔ **⚙️ پنل مدیریت** وارد پنل می‌شوید.
2. از **🏦 کارت‌ها** شمارهٔ کارت دریافت وجه را اضافه کنید.
3. از **📦 تعرفه‌ها** تعرفهٔ ماهانه را تنظیم کنید (یک تعرفهٔ پیش‌فرض ساخته شده است).
4. از **⚙️ تنظیمات** دامنه/IP سرور، رم/CPU هر ربات و متن‌ها را ست کنید.
5. با یک اکانت دیگر **🎁 تست رایگان** را امتحان کنید تا ببینید ساخت ربات کار می‌کند.

راهنمای کامل پنل: [ربات‌ساز](/docs/builder).

## ساختار فایل‌ها روی سرور

<Files>
  <Folder name="/opt/mdjebot" defaultOpen>
    <File name=".env — تنظیمات اصلی (دسترسی 600)" />
    <File name="docker-compose.yml" />
    <File name="mdjebot.sh — اسکریپت مدیریت" />
    <File name=".install_mode / .install_branch" />
    <Folder name="builder — سشن تلگرام ربات‌ساز" />
    <Folder name="tenants — پوشهٔ هر ربات مشتری (شامل توکن؛ دسترسی 700)" />
    <Folder name="data" defaultOpen>
      <Folder name="mariadb — دیتای دیتابیس‌ها" />
      <Folder name="redis" />
    </Folder>
  </Folder>
</Files>

| کانتینر | ایمیج | پورت |
|---------|-------|------|
| `mdjebot-builder` | `ghcr.io/mdjes/mdjebot` | — |
| `mdjebot-t<شماره>` (هر ربات مشتری) | همان ایمیج | یک پورت از `7000`–`7999` |
| `mdjebot-mariadb` | `mariadb:12` | `127.0.0.1:6162` |
| `mdjebot-redis` | `redis:8-alpine` | `127.0.0.1:6161` |
| `mdjebot-phpmyadmin` | `phpmyadmin:5-apache` | `6163` (همهٔ اینترفیس‌ها) |

<Callout type="warn" title="phpMyAdmin">
phpMyAdmin به دیتابیس همهٔ مشتری‌ها دسترسی دارد. اگر لازم ندارید، پورت `6163` را در فایروال ببندید یا کانتینرش را متوقف کنید.
</Callout>

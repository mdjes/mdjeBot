**MdjeBot** یک **ربات‌ساز** است: شما تعرفهٔ ماهانه تعیین می‌کنید، مشتری تعرفه را می‌خرد و توکن رباتش را می‌فرستد، و همین سورس برای او به یک **ربات فروش وی‌پی‌ان** مستقل روی پنل [پاسارگارد](https://github.com/PasarGuard/panel) تبدیل می‌شود.

ربات فروشی که برای هر مشتری ساخته می‌شود این امکانات را دارد: خرید، تحویل آنی کانفیگ، تمدید، شارژ کیف پول، تست رایگان، نمایندگی و پشتیبانی همه داخل تلگرام انجام می‌شود. کنار ربات، یک **وب‌اپ (Mini App)** برای کاربران و یک **پنل مدیریت تحت وب** برای ادمین هم وجود دارد.

<ZoomImage src="/images/hero/webapp-user.webp" alt="وب‌اپ کاربر MdjeBot" />

## امکانات در یک نگاه

| بخش | امکانات |
|------|---------|
| فروش | چند پنل همزمان، پلن حجمی / مصرف منصفانه / نامحدود، نمایش کلاسیک یا «اول زمان»، خرید دلخواه حجم و زمان، لوکیشن‌های فاکتور |
| مدیریت سرویس | تمدید، حجم و زمان اضافه، QR، تغییر لینک و ساب، لینک‌های تکی، کلاینت‌ها، نمودار مصرف، واگذاری کانفیگ |
| پرداخت | کارت‌به‌کارت با رسید و تایید خودکار، ارز دیجیتال (TRX، USDT روی سه شبکه، TON، POL)، استارز تلگرام، درگاه TonPays، پرداخت مستقیم، بونوس شارژ |
| بازاریابی | کد تخفیف عمومی/اختصاصی و لینک‌دار، سیستم دعوت دوستان با درآمد قابل برداشت، پیام و فوروارد همگانی، قفل کانال، گزارش خرید عمومی |
| نمایندگی | فروش پنل ادمین پاسارگارد (ثابت، نامحدود، مصرفی یا ساعتی)، صورت‌حساب خودکار، تمدید و روز/حجم/یوزر اضافه |
| شخصی‌سازی | ویرایش همهٔ متن‌ها و دکمه‌ها، رنگ و ایموجی پریمیوم، چیدمان منو، راهنما و اپ‌های دانلود |
| نگهداری | بکاپ خودکار، لاگ‌های تفکیک‌شده، اطلاع‌رسانی حجم/زمان با وب‌هوک، مایگریشن از ربات‌های دیگر، اسکریپت مدیریت سرور |
